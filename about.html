About The Author

Hi, my name is Jessie, and I'm the author of The Night Class. I created this comic as my final project for a class I took on vampires at ASU. It was a very challenging class, but I learned a lot about vampires and wanted to bring forth my own spin on the concept in a modern context.

As for this website, it was created as the final project for my web design class. It was a bit of a rush job, but I'm very proud of it. Most of all, I'm proud of the fact that the read comic section is fully functional without CSS. Each page has its own HTML file, with the help of a python script I made that generated copies of a template page based on the first page.
